nSOFA - Neonatal Sequential Organ Failure Assessment

Referências: Protocolos de Terapia Intensiva Pediátrica e Neonatal.

Como usar — nSOFA (educativo)

×

Objetivo (educativo)

O nSOFA organiza parâmetros clínicos para estimativa educativa de disfunção orgânica neonatal. O uso nesta página é informativo e não substitui avaliação clínica, protocolos institucionais ou prescrição.

Fórmula do nSOFA

nSOFA = Sistema Cardiovascular + Sistema Respiratório + Sistema Hematológico + Sistema Neurológico + Sistema Hepático + Sistema Renal

Cada sistema é pontuado de 0-4 pontos:
• 0 pontos: Função normal
• 1-2 pontos: Disfunção leve a moderada
• 3-4 pontos: Disfunção grave a falência

Escala Total: 0-24 pontos (quanto maior, pior prognóstico)

Sistemas Avaliados

  • Sistema Cardiovascular: Pressão arterial, uso de vasopressores
  • Sistema Respiratório: Oxigenação, suporte ventilatório
  • Sistema Hematológico: Plaquetas, uso de transfusões
  • Sistema Neurológico: Nível de consciência, convulsões
  • Sistema Hepático: Bilirrubina total
  • Sistema Renal: Creatinina, diurese

Instruções de Uso

  1. Dados Cardiovasculares: Informe PAM e uso de vasopressores
  2. Dados Respiratórios: Informe PaO2/FiO2 e tipo de suporte
  3. Dados Hematológicos: Informe contagem de plaquetas
  4. Dados Neurológicos: Informe nível de consciência e convulsões
  5. Dados Hepáticos: Informe bilirrubina total em mg/dL
  6. Dados Renais: Informe creatinina em mg/dL e diurese
  7. Clique em "Calcular nSOFA" para obter o escore

Interpretação dos Resultados

  • 0-6 pontos: Baixo risco de mortalidade
  • 7-12 pontos: Risco moderado de mortalidade
  • 13-18 pontos: Alto risco de mortalidade
  • 19-24 pontos: Muito alto risco de mortalidade
  • Mudança no escore: Melhora ou piora da disfunção orgânica

Considerações Importantes

  • Use valores atuais ou piores das últimas 24 horas
  • Pode ser calculado seriamente para monitorar evolução
  • Útil para identificar falência de múltiplos órgãos
  • Complementar à avaliação clínica individual
  • Valores laboratoriais devem ser recentes
  • Considerar idade gestacional e peso
  • Reavaliar conforme evolução clínica

Aplicações Clínicas

  • Prognóstico: Estimativa de mortalidade
  • Monitoramento: Evolução da disfunção orgânica
  • Pesquisa: Classificação de gravidade
  • Qualidade: Comparação entre UTINs
  • Triagem: Identificação de pacientes de alto risco

Limitações

  • Não substitui avaliação clínica individual
  • Validação limitada em diferentes populações
  • Pode não capturar todas as nuances clínicas
  • Depende da disponibilidade de exames laboratoriais
