Informacoes sobre o PELD Score

  • PELD é usado para priorizar crianças na lista de transplante hepático
  • Score mais alto indica maior urgência para transplante
  • Usado para pacientes com idade < 12 anos
  • Considera função hepática, crescimento e complicações
  • Atualizado regularmente conforme condição clínica

Formula do PELD Score

PELD = 0.436 x ln(Bilirrubina) + 0.957 x ln(INR) - 0.687 x ln(Albumina) + 0.480 x Crescimento + 0.667 x Colangite

Se idade < 12 meses: PELD = PELD + 0.436

Objetivo (educativo)

Esta calculadora organiza variáveis para estimar o PELD como apoio informativo na avaliação de gravidade hepática pediátrica. O resultado não substitui avaliação clínica, protocolo institucional ou prescrição.

Fórmula PELD

Fórmula PELD:

PELD = 10 x [0.480 x ln(Bilirrubina) + 1.857 x ln(INR) - 0.687 x ln(Albumina) + 0.436 x (Idade < 1 ano) + 0.667 x (Crescimento < -2 DP)]

Variáveis:
- Bilirrubina Total: mg/dL
- INR: International Normalized Ratio
- Albumina: g/dL
- Idade < 1 ano: 1 se verdadeiro, 0 se falso
- Crescimento < -2 DP: 1 se verdadeiro, 0 se falso

Limitações:
- Bilirrubina < 1.0 -> usar 1.0
- INR < 1.0 -> usar 1.0
- Albumina < 1.0 -> usar 1.0

Interpretação:
- 0-9: Baixo risco
- 10-19: Risco moderado
- 20-29: Alto risco
- 30-39: Muito alto risco
- >= 40: Risco extremo

Parâmetros Avaliados

  • Bilirrubina Total: mg/dL
  • INR: International Normalized Ratio
  • Albumina: g/dL
  • Idade: < 1 ano
  • Crescimento: < -2 DP
  • PELD Score: 0-100

Instruções de Uso

  1. Insira Bilirrubina: Total mg/dL
  2. Informe INR: International Normalized Ratio
  3. Insira Albumina: g/dL
  4. Informe Idade: < 1 ano (sim/não)
  5. Informe Crescimento: < -2 DP (sim/não)
  6. Calcule: Sistema calcula automaticamente

Interpretação do PELD

  • 0-9: Doença hepática leve
  • 10-19: Doença hepática moderada
  • 20-29: Doença hepática grave
  • 30-39: Doença hepática muito grave
  • >= 40: Doenca hepatica terminal
  • PELD 15+: Considerar transplante
  • PELD 25+: Prioridade alta
  • PELD 35+: Prioridade máxima

Diferenças PELD vs MELD

  • PELD: Inclui idade e crescimento
  • MELD: Inclui creatinina
  • PELD: Não inclui creatinina
  • MELD: Não inclui albumina
  • PELD: Específico pediátrico
  • MELD: Adultos e pediátricos
  • PELD: Considera crescimento
  • MELD: Considera função renal
