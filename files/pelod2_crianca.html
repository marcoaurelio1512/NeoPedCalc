Informações importantes

O PELOD-2 deve ser calculado com base nos piores valores do dia para cada variável. Para cada parâmetro, use o valor que representa a maior disfunção observada durante as 24 horas. Você pode inserir valores únicos ou listas separadas por vírgula — o sistema seleciona automaticamente o pior valor conforme a regra (mínimo ou máximo, conforme o parâmetro).

Uso desta tela: apoio ao ensino e registro informativo. O número percentual associado ao total é uma transformação logística do escore derivada da publicação de referência — não é probabilidade clínica individual nem critério isolado de conduta.

Objetivo (educativo)

O PELOD-2 quantifica disfunção orgânica pediátrica a partir de variáveis fisiológicas/laboratoriais. Nesta página ele serve para estudo, treino e registro informativo. O percentual mostrado aplica a função logística publicada por Leteurtre et al. ao total calculado — é uma curva populacional de referência, não uma “chance” individual do paciente.

Modelo implementado (PELOD-2 publicado)

Total = pontos neurológicos + cardiovasculares + renais + respiratórios + hematológicos (10 variáveis, total de 0 a 33 pontos; Leteurtre et al., 2013).

Neurológico
• Glasgow: ≥ 11 = 0; 5–10 = 1; 3–4 = 4
• Reação pupilar: ambas reativas = 0; ambas fixas = 5

Cardiovascular
• Lactato (mmol/L): < 5,0 = 0; 5,0–10,9 = 1; ≥ 11,0 = 4
• PAM (mmHg) por faixa etária, pontos 0 / 2 / 3 / 6:
  0 a < 1 mês: ≥ 46 / 31–45 / 17–30 / ≤ 16
  1–11 meses: ≥ 55 / 39–54 / 25–38 / ≤ 24
  12–23 meses: ≥ 60 / 44–59 / 31–43 / ≤ 30
  24–59 meses: ≥ 62 / 46–61 / 32–45 / ≤ 31
  60–143 meses: ≥ 65 / 49–64 / 36–48 / ≤ 35
  ≥ 144 meses: ≥ 67 / 52–66 / 38–51 / ≤ 37

Renal
• Creatinina (µmol/L) ≥ limiar da idade = 2, abaixo = 0: 0 a < 1 mês ≥ 70; 1–11 meses ≥ 23; 12–23 meses ≥ 35; 24–59 meses ≥ 51; 60–143 meses ≥ 59; ≥ 144 meses ≥ 93 (mg/dL × 88,4 = µmol/L)

Respiratório
• PaO₂ (mmHg)/FiO₂: ≥ 61 = 0; ≤ 60 = 2
• PaCO₂ (mmHg): ≤ 58 = 0; 59–94 = 1; ≥ 95 = 3
• Ventilação invasiva: não = 0; sim = 3

Hematológico
• Leucócitos (×10⁹/L): > 2 = 0; ≤ 2 = 2
• Plaquetas (×10⁹/L): ≥ 142 = 0; 77–141 = 1; ≤ 76 = 2

Valores entre faixas inteiras: cada faixa começa no seu limite inferior publicado (ex.: PAM 30,5 em neonato pontua como 17–30; PaO₂/FiO₂ 60,5 pontua 0).
Variável não informada: conta 0 ponto e é listada abaixo do resultado.

Instruções de uso

  1. Preencha os piores valores de cada parâmetro nas últimas 24 h (ou janela definida pelo seu serviço)
  2. Informe a data de nascimento ou escolha a faixa etária: os limiares de PAM e creatinina dependem da idade
  3. Use vírgula para listar vários valores; o sistema escolhe o pior conforme a regra do parâmetro (menor valor para Glasgow, PAM, PaO₂, leucócitos e plaquetas; maior valor para lactato, FiO₂, PaCO₂ e creatinina)
  4. Informe FiO₂ como fração, com ponto decimal (ex.: 0.6 para 60%); a vírgula separa valores da lista
  5. Clique em Calcular PELOD-2 para ver total, tabela de contribuição e probabilidade de óbito do modelo
  6. Use Copiar texto apenas como rascunho educativo — revise antes de arquivar

Sobre o percentual exibido

O valor em % é a probabilidade de óbito estimada pelo modelo da publicação: logit = −6,61 + 0,47 × PELOD-2; p = 1 / (1 + e^(−logit)). Descreve a coorte de derivação da publicação (UTIs pediátricas europeias); interpretação adequada exige contexto epidemiológico e clínico; não use como único critério de decisão terapêutica.

Considerações importantes

  • Qualidade e sincronia dos exames influenciam o total
  • Evolução seriada do escore pode ser discutida na literatura; a decisão de frequência de coleta é assistencial
  • Comorbidades e terapias (ex.: sedação) alteram a leitura dos parâmetros — não estão “corrigidas” automaticamente nesta tela

Uso pretendido (informativo)

  • Ensino de definição de disfunção orgânica pediátrica
  • Padronização de registro para estudo ou auditoria interna, com ressalvas explícitas
  • Comparação com artigos e bases de dados de UTI pediátrica

Limitações

  • Não substitui avaliação clínica individual nem escores institucionais obrigatórios
  • Validação e performance variam por população e cenário assistencial
  • Depende da disponibilidade e acurácia dos dados inseridos
