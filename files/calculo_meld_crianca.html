Interpretacao dos Resultados

Informacoes sobre o MELD Score

  • MELD e usado para priorizar pacientes >= 12 anos na lista de transplante hepatica
  • MELD-Na incorpora o sódio sérico para maior precisão
  • Score mais alto indica maior urgência para transplante
  • Estimativa de mortalidade em 90 dias
  • Atualizado regularmente conforme condição clínica
  • Valores mínimos: Creatinina, Bilirrubina e INR = 1.0
  • Valor máximo: Creatinina = 4.0 mg/dL

Formulas do MELD Score

MELD Score:
MELD = 9.6 x ln(Creatinina) + 3.8 x ln(Bilirrubina) + 11.2 x ln(INR) + 6.4
MELD-Na Score:
MELD-Na = MELD + 1.32 x (137 - Sodio) - [0.033 x MELD x (137 - Sodio)]
Regras de Ajuste:
- Creatinina, Bilirrubina, INR: minimo 1.0
- Creatinina: maximo 4.0 mg/dL
- Sodio: minimo 125, maximo 137 mEq/L
- Dialise: Creatinina = 4.0 mg/dL

Objetivo (educativo)

Esta calculadora organiza variáveis para estimar MELD/MELD-Na como apoio informativo na avaliação de gravidade hepática. O resultado não substitui avaliação clínica, protocolo institucional ou prescrição.

Fórmula MELD

Fórmula MELD Pediátrica:

MELD = 10 x [0.957 x ln(Creatinina) + 0.378 x ln(Bilirrubina) + 1.120 x ln(INR) + 0.643]

Variáveis:
- Creatinina: mg/dL (minimo 1.0)
- Bilirrubina Total: mg/dL
- INR: International Normalized Ratio

Limitações:
- Creatinina < 1.0 -> usar 1.0
- Bilirrubina < 1.0 -> usar 1.0
- INR < 1.0 -> usar 1.0

Interpretação:
- 0-9: Baixo risco
- 10-19: Risco moderado
- 20-29: Alto risco
- 30-39: Muito alto risco
- >= 40: Risco extremo

Parâmetros Avaliados

  • MELD Score: 0-100

Interpretação do MELD

  • 0-9: Doença hepática leve
  • 10-19: Doença hepática moderada
  • 20-29: Doença hepática grave
  • 30-39: Doença hepática muito grave
  • >= 40: Doenca hepatica terminal
  • MELD 15+: Considerar transplante
  • MELD 25+: Prioridade alta
  • MELD 35+: Prioridade máxima

Causas de Doença Hepática

  • Virais: Hepatite B, C
  • Autoimunes: Hepatite autoimune
  • Metabólicas: Wilson, hemocromatose
  • Tóxicas: Medicamentos, álcool
  • Colestáticas: Atresia biliar
  • Vasculares: Síndrome de Budd-Chiari
  • Congênitas: Fibrose cística
  • Idiopáticas: Criptogênica

Complicações da Doença Hepática

  • Hipertensão Portal: Varizes
  • Ascite: Líquido peritoneal
  • Encefalopatia: Hepática
  • Síndrome Hepatorenal: Insuficiência
  • Síndrome Hepatopulmonar: Hipoxemia
  • Coagulopatia: Hemorragias
  • Infecções: Espontâneas
  • Câncer: Hepatocarcinoma

Fatores que Influenciam MELD

  • Função Renal: Creatinina
  • Função Hepática: Bilirrubina
  • Coagulação: INR
  • Idade: Pediátrica
  • Comorbidades: Outras doenças
  • Medicamentos: Anticoagulantes
  • Desidratação: Creatinina
  • Transfusões: Bilirrubina

Indicações para Transplante

  • MELD >= 15: Considerar
  • MELD >= 25: Prioridade alta
  • MELD >= 35: Prioridade maxima
  • Complicações: Refratárias
  • Qualidade de Vida: Comprometida
  • Prognóstico: < 1 ano
  • Câncer: Hepatocarcinoma
  • Metabólicas: Erro inato

Contraindicações Transplante

  • Infecção: Ativa
  • Malignidade: Extra-hepática
  • Dependência: Álcool/drogas
  • Psiquiátricas: Graves
  • Cardiopulmonares: Graves
  • Neurológicas: Irreversíveis
  • Idade: Muito avançada
  • Suporte: Social inadequado

Prognóstico

  • MELD < 10: Sobrevida > 90% (3 meses)
  • MELD 10-19: Sobrevida 70-90%
  • MELD 20-29: Sobrevida 40-70%
  • MELD 30-39: Sobrevida 20-40%
  • MELD >= 40: Sobrevida < 20%
  • Transplante: Melhora prognóstico
  • Complicações: Pioram
  • Pediátrico: Melhor que adulto
